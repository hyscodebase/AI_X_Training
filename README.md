# AI+X Applied AI Service Portfolio

> **AI Service Planning · Machine Learning · RAG Agent · Data-Driven Product Development**

본 리포지토리는 **융합공과대학 AI+X 선도인재양성 마이크로전공** 과정에서 수행한 AI 프로젝트 포트폴리오입니다.  
사용자에게 실질적으로 유의미한 AI 경험을 제공하기 위해, 데이터 수집부터 전처리, EDA, 모델링, 평가, 서비스 기획까지 AI 서비스 개발의 전 과정을 프로젝트 기반으로 수행했습니다.

본 프로젝트는 단순한 모델 구현을 넘어, 실제 문제 상황과 사용자 니즈를 기반으로 한 **AI Solution Design**과 **Product Requirement Document(PRD)** 작성까지 포함합니다.

---

## Project Overview

본 과정에서는 현장 중심의 데이터셋을 활용하여 문제를 정의하고, 이를 해결하기 위한 AI 모델 및 서비스 개발 프로세스를 학습했습니다.

주요 프로젝트 주제는 다음과 같습니다.

- **Human Activity Data Analysis**
- **Fine Dust Data Analysis**
- **File Management RAG Agent**
- **Autonomous AI Project**

각 프로젝트는 데이터 분석 역량을 기반으로 Machine Learning 모델 구축, 성능 평가, 결과 해석, 서비스 적용 가능성 검토까지 포함합니다.

## Key Projects

## 1. Human Activity Data Analysis

사용자의 행동 데이터를 분석하여 활동 패턴을 이해하고, 이를 기반으로 분류 또는 예측 모델을 구축하는 프로젝트입니다.

### Key Tasks

- Human Activity Data 수집 및 구조 파악
- 데이터 전처리 및 Feature Engineering
- Exploratory Data Analysis 수행
- Machine Learning 기반 Activity Classification
- 모델 성능 평가 및 결과 해석

### Expected Outcome

사용자의 활동 패턴을 기반으로 한 행동 인식 모델을 구현하고, 향후 헬스케어, 피트니스, 스마트홈 서비스 등에 적용 가능한 AI 서비스 아이디어를 도출합니다.

---

## 2. Fine Dust Data Analysis

미세먼지 데이터를 기반으로 환경 데이터를 분석하고, 대기질 예측 또는 위험도 판단을 위한 AI 모델을 설계하는 프로젝트입니다.

### Key Tasks

- 미세먼지 및 환경 변수 데이터 분석
- 결측치 처리 및 시계열 데이터 전처리
- PM10, PM2.5 등 주요 변수에 대한 EDA
- Fine Dust Prediction Model 구축
- 예측 결과 기반 서비스 활용 방안 제안

### Expected Outcome

대기질 예측 모델을 통해 사용자에게 미세먼지 위험도를 사전에 제공하는 AI 기반 환경 정보 서비스의 가능성을 검토합니다.

---

## 3. File Management RAG Agent

파일 관리 업무를 효율화하기 위해 **RAG(Retrieval-Augmented Generation)** 기반 Agent를 설계한 프로젝트입니다.  
사용자가 보유한 문서나 파일 정보를 기반으로 질의응답, 요약, 검색, 정리 기능을 제공하는 AI Agent를 목표로 합니다.

### Key Tasks

- 문서 및 파일 데이터 구조화
- Text Chunking 및 Embedding 생성
- Vector Database 기반 검색 구조 설계
- Retrieval-Augmented Generation Pipeline 구성
- File Search, Summarization, Q&A 기능 기획

### Expected Outcome

사용자가 복잡한 파일 시스템에서 필요한 정보를 빠르게 찾을 수 있도록 돕는 **AI-powered File Management Agent**를 설계합니다.

---

## 4. Autonomous AI Project

수업에서 학습한 EDA, ML, AI Service Planning 역량을 바탕으로 자율 프로젝트를 수행했습니다.  
문제 정의부터 데이터 분석, 모델 개발, 서비스 기획까지 전 과정을 독립적으로 설계하는 것을 목표로 했습니다.

### Key Tasks

- Problem Definition
- Dataset Selection
- EDA & Insight Discovery
- ML Model Development
- Evaluation & Interpretation
- PRD 작성
- AI Paper Draft 작성

### Expected Outcome

단순 분석 결과물이 아닌, 실제 서비스 또는 연구 결과물로 확장 가능한 프로젝트 산출물을 제작합니다.
